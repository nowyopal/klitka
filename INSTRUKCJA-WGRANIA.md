# Jak wgrać grę na GitHuba

1. Utwórz nowe repozytorium i pozostaw je puste — nie dodawaj automatycznie README, `.gitignore` ani licencji.
2. Po utworzeniu repozytorium wybierz link **uploading an existing file**.
3. Otwórz na komputerze folder `KLITKA-GITHUB-READY`.
4. Zaznacz całą zawartość folderu, a nie sam folder i nie plik ZIP.
5. Przeciągnij zaznaczone pliki oraz folder `assets` do okna GitHuba.
6. Poczekaj, aż wszystkie pliki zakończą wysyłanie.
7. W polu opisu wpisz `Pierwsza wersja KLITKI` i kliknij **Commit changes**.

Nie wgrywaj pliku ZIP do repozytorium. ZIP służy wyłącznie do pobrania i rozpakowania na komputerze.
