# KLITKA

Satyryczna mobilna gra aukcyjna o kupowaniu absurdalnie małych mieszkań.

## Zasady

- Każdy gracz zaczyna z budżetem 5 000 000 zł.
- Przed każdą aukcją wszyscy gracze muszą nacisnąć „Jestem gotowy”.
- Cena mieszkania spada z 2 000 000 zł do zera w ciągu 8 sekund.
- Pierwsza osoba, która naciśnie „Kupuję!”, otrzymuje mieszkanie i płaci aktualną cenę.
- Wygrywa osoba z największym łącznym miesięcznym czynszem. Niewydane pieniądze nie dają punktów.

Gra obsługuje 2–6 osób na osobnych telefonach oraz lokalny tryb demonstracyjny z botami.

## Publikacja na Render

1. Wgraj całą zawartość tego folderu bezpośrednio do katalogu głównego repozytorium na GitHubie.
2. W Render wybierz **New → Blueprint**.
3. Połącz repozytorium z grą.
4. Render odczyta plik `render.yaml`, uruchomi testy i wystartuje serwer.

Pierwsze otwarcie darmowej usługi po dłuższej przerwie może potrwać kilkadziesiąt sekund.
